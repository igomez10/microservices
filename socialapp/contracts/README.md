# Pact Contracts

This folder holds the contract artifacts generated by the Pact consumer tests.

- `pacts/` contains the committed contracts:
  - `socialapp-urlshortener.json` captures how `socialapp` interacts with the `urlshortener` service.
  - `socialapp-client-socialapp.json` records how external clients are expected to call Socialapp's user, comment,
    and scope APIs.
- `logs/` is where Pact writes mock server logs and is ignored by version control.

Regenerate the contracts by running `make contract-test` from `socialapp/` after installing the Pact CLI and
native libraries (see the main `README.md` for how to install `pact-go`).

Publish both pact files to your broker with:

```sh
scripts/publish-contracts.sh \
  contracts/pacts/socialapp-client-socialapp.json \
  contracts/pacts/socialapp-urlshortener.json
```
